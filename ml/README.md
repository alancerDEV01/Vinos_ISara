# Aprendizaje automático

El ML no forma parte del puntaje oficial del MVP.

Orden obligatorio:

1. recopilar feedback con consentimiento;
2. congelar dataset y esquema de características;
3. crear baseline interpretable;
4. evaluar por regiones, perfiles y roles;
5. ejecutar en shadow mode;
6. promover sólo con aprobación y rollback disponible.
