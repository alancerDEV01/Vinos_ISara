# Biblioteca visual por departamento

Cada departamento separa fotografías de `lugares/` y `platos/`.

El archivo `media-manifest.json` conserva el título, autor, fuente y licencia
devueltos por Wikimedia Commons. Las descargas son un lote inicial y deben
pasar revisión editorial antes de mostrarse como contenido definitivo.

  devolvió una estampilla y no un paisaje amazónico.
- Revisar: `chuquisaca/platos/mondongo.jpg` es una composición de restaurante,
  no una fotografía aislada del plato.

No se deben inferir identidad, ubicación o tradición solamente desde el nombre
del archivo. La asociación final se aprueba junto con los datos del catálogo.
